# Changelogs

Package changes are recorded next to each package in `packages/*/CHANGELOG.md`.
The existing Hey API release history is preserved in
`packages/hey-api-builders/CHANGELOG.md`. New toolkit packages and the shared-runtime
Hey API integration are being prepared on the `next` prerelease channel.

Use Changesets from the repository root to coordinate package versions. Neither
merging a pull request nor committing a changeset publishes packages automatically.
